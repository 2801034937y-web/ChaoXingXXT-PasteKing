## 二、实现原理
学习通的“禁止粘贴”，本质是监听并阻止`paste`事件，而 粘贴王 通过将文本拆成单字逐个派发 `keydown` / `keypress` / `keyup`，用 `execCommand('insertText')` 写入，最后补发 `input` / `change` 事件，从而实现模拟用户键入


## 三、如何使用

### 1，插件

1. 解压缩“PasteKing.zip”
2. 浏览器打开“扩展”，打开“开发人员模式”
3. 点击“加载解压缩的扩展”，选择“PasteKing”文件夹，随后打开扩展即可

### 2，源代码

1. 浏览器登录你的学习通，打开你的作业界面，按下F12或Ctrl+Shift+J
2. 找到“源代码”选项，点击；找到“片段”选项，点击
![片段](图片地址)
3. 添加一个新片段，把“复制我.txt”粘贴进去，并Ctrl+Enter运行即可
